# dom-to-pptx-skills

Interactive CLI installer to configure `dom-to-pptx` presentation engineering skills for AI agents.

## Usage

```bash
# Dedicated CLI
npx dom-to-pptx-skills

# Or via unified router
npx dom-to-pptx skills
```

This starts the interactive menu to auto-configure presentation engineering skills for Claude Code, Gemini CLI, Cursor, Windsurf, or locally in your project folder (`.agent/skills`).
