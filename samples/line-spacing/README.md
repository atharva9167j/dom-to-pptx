# Relative line-spacing sample

`relative-line-spacing.pptx` is generated from `fixture.html` at a 1920 x 1080 browser viewport and a 10 x 5.625 inch slide.

The wrapping paragraph remains one editable text box. Its line-spacing XML changes from:

```xml
<a:lnSpc><a:spcPts val="938"/></a:lnSpc>
```

to:

```xml
<a:lnSpc><a:spcPct val="130208"/></a:lnSpc>
```
